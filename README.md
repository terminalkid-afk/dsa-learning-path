## 🎯 Why This Repository?

If you've ever looked at a DSA implementation and thought, *"I understand the code, but I don't understand why it works,"* this repo is for you. Every single topic follows a strict **educational loop**:

1. **The Analogy**: We explain the concept using real-world examples (like Pez dispensers for Stacks or train cars for Linked Lists).
2. **The Visual Logic**: We break down the step-by-step movement of data.
3. **The Complexity**: Clear $O(n)$ analysis so you know exactly how your code performs.
4. **The Implementation**: Clean, PEP-8 compliant Python code with zero over-engineering.
5. **The Practice**: Direct links to LeetCode and GeeksforGeeks problems to test your knowledge.

## 🗺️ The Learning Roadmap

Follow this sequence to build your knowledge from the ground up:

### 🟢 Level 1: The Basics (Linear Data Structures)
- [ ] **01 Arrays** $\rightarrow$ Searching (Linear, Binary) $\mid$ Sorting (Bubble, Selection, Insertion, Merge, Quick)
- [ ] **02 Stacks** $\rightarrow$ LIFO Logic $\mid$ Polish Notation $\mid$ Array & LL Implementations
- [ ] **03 Queues** $\rightarrow$ FIFO Logic $\mid$ Circular & Priority Queues $\mid$ Array & LL Implementations
- [ ] **04 Linked Lists** $\rightarrow$ Singly, Doubly, Circular $\mid$ Insertion, Deletion, Reversing & Merging

### 🟡 Level 2: Hierarchical Structures (Non-Linear)
- [ ] **05 Trees** $\rightarrow$ Binary Trees $\mid$ BSTs $\mid$ AVL Balancing $\mid$ DFS/BFS Traversals $\mid$ Tries $\mid$ Segment Trees
- [ ] **06 Graphs** $\rightarrow$ Matrix vs List $\mid$ BFS/DFS $\mid$ Dijkstra $\mid$ Prim's $\mid$ Kruskal's $\mid$ Topological Sort

## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/dsa-learning-path.git
cd dsa-learning-path
```

### 2. Explore a Lesson
Navigate to any folder to find the lesson and the code. For example, to learn about **Binary Search**:
```bash
cd 01-Arrays/Searching/Binary-Search
# Read the README.md for the intuition
# Run the code:
python binary_search.py
```
